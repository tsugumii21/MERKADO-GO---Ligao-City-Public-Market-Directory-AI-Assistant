# Part 10 — Environment & Deployment

## Environment Variables (`.env`)

The app uses `flutter_dotenv` to load API keys from a `.env` file at the project root. This file is **NOT committed to git** (it's in `.gitignore`).

### `.env.example` Template

Create a `.env` file by copying `.env.example` and filling in your actual keys:

```env
# ── Google Gemini AI ──────────────────────────────
GEMINI_API_KEY=your_gemini_api_key_here

# ── Google Maps ───────────────────────────────────
GOOGLE_MAPS_API_KEY=your_google_maps_api_key_here

# ── Cloudinary Image Storage ──────────────────────
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret
CLOUDINARY_UPLOAD_PRESET=merkadogo
CLOUDINARY_URL=https://api.cloudinary.com/v1_1/your_cloud_name
```

### Where to Get Each Key

| Key | Where to Get It | Steps |
|-----|----------------|-------|
| `GEMINI_API_KEY` | [Google AI Studio](https://aistudio.google.com/app/apikey) | Create a project → Generate API key → Copy |
| `GOOGLE_MAPS_API_KEY` | [Google Cloud Console](https://console.cloud.google.com/) | Enable "Maps JavaScript API" + "Maps SDK for Android" → Create credentials → Copy API key |
| `CLOUDINARY_*` | [Cloudinary Dashboard](https://cloudinary.com/console) | Sign up → Dashboard shows cloud name, API key, API secret. Create an **unsigned upload preset** named `merkadogo` under Settings → Upload |

## Firebase Configuration

Firebase is already configured in the project via `lib/firebase_options.dart` (auto-generated by FlutterFire CLI).

### If You Need to Reconfigure Firebase

```bash
# Install FlutterFire CLI
dart pub global activate flutterfire_cli

# Run configuration (generates firebase_options.dart)
flutterfire configure
```

### Firebase Console Setup Checklist

| Service | Setup Required |
|---------|---------------|
| **Authentication** | Enable "Email/Password" sign-in provider |
| **Cloud Firestore** | Create database in production or test mode |
| **Firestore Rules** | Deploy security rules (see below) |
| **Firestore Indexes** | Create composite index: `stalls` → `isActive` ASC + `name` ASC |

### Recommended Firestore Security Rules

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Users collection
    match /users/{userId} {
      allow read: if request.auth != null;
      allow write: if request.auth != null && request.auth.uid == userId;
    }
    
    // Usernames collection (public read for availability check)
    match /usernames/{username} {
      allow read: if true;
      allow write: if request.auth != null;
    }
    
    // Stalls collection
    match /stalls/{stallId} {
      allow read: if request.auth != null;
      allow write: if request.auth != null && 
        get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == 'admin';
    }
    
    // Reports collection
    match /reports/{reportId} {
      allow read: if request.auth != null;
      allow create: if request.auth != null;
      allow update, delete: if request.auth != null && 
        get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == 'admin';
    }
  }
}
```

## Google Maps Platform Setup

### Android
The API key is set in `android/app/src/main/AndroidManifest.xml`:

```xml
<meta-data
    android:name="com.google.android.geo.API_KEY"
    android:value="YOUR_GOOGLE_MAPS_API_KEY"/>
```

**Required APIs** (enable in Google Cloud Console):
- Maps SDK for Android

### Web
The API key is loaded dynamically from `.env` at runtime (no hardcoded key in `index.html`).

**Required APIs** (enable in Google Cloud Console):
- Maps JavaScript API

## Platform-Specific Notes

### Android

| Config | Location | Notes |
|--------|----------|-------|
| Min SDK | `android/app/build.gradle` | Check `minSdkVersion` (must be ≥ 21 for Google Maps) |
| Maps API Key | `android/app/src/main/AndroidManifest.xml` | Set your key in the `com.google.android.geo.API_KEY` meta-data |
| Permissions | `android/app/src/main/AndroidManifest.xml` | `ACCESS_FINE_LOCATION`, `ACCESS_COARSE_LOCATION`, `CAMERA`, `INTERNET` |
| `google-services.json` | `android/app/google-services.json` | Firebase config file (auto-generated by `flutterfire configure`) |

### Web

| Config | Location | Notes |
|--------|----------|-------|
| Maps API | Loaded dynamically in `main()` | No need to edit `index.html` |
| Firebase | `web/index.html` (or `firebase_options.dart`) | Already configured |
| `index.html` | `web/index.html` | Base href, favicon, app title |
| CORS | Cloudinary | Cloudinary handles CORS for uploads automatically |

### Web Compatibility Considerations

| Feature | Android | Web | Notes |
|---------|---------|-----|-------|
| Google Maps | ✅ Native SDK | ✅ JavaScript API | Different underlying implementations |
| Image Picker | ✅ `dart:io` File | ✅ `Uint8List` bytes | Already refactored for web compatibility |
| Location | ✅ `geolocator` | ⚠️ Limited | Web uses browser's Geolocation API, `permission_handler` guarded with `kIsWeb` |
| Push Notifications | ⚠️ Stub | ⚠️ Stub | Not yet implemented on either platform |

## Seed Data

The project includes seed data utilities for populating the database with test stalls:

| File | Purpose |
|------|---------|
| `lib/data/seed_stalls.dart` | List of predefined market stalls with sample data |
| `lib/seed_data_app.dart` | Standalone app that uploads seed stalls to Firestore |
| `lib/update_coordinates_app.dart` | Standalone app that updates stall GPS coordinates in bulk |

### How to Run Seed Data

```bash
# Run the seed data app (uploads stalls to Firestore)
flutter run -t lib/seed_data_app.dart

# Run the coordinate updater
flutter run -t lib/update_coordinates_app.dart
```

> ⚠️ **Warning**: Seed data apps write directly to your Firestore database. Only run these on development/staging databases, not production.

## Troubleshooting

### Common Issues

| Issue | Solution |
|-------|----------|
| `flutter pub get` fails | Run `flutter clean` then `flutter pub get` again |
| Google Maps blank on web | Check that `GOOGLE_MAPS_API_KEY` is set in `.env` and "Maps JavaScript API" is enabled in Google Cloud Console |
| Google Maps blank on Android | Check `AndroidManifest.xml` API key and "Maps SDK for Android" is enabled |
| Cloudinary uploads fail | Verify all `CLOUDINARY_*` keys in `.env`. Check that upload preset `merkadogo` exists and is set to "unsigned" |
| AI chatbot not responding | Verify `GEMINI_API_KEY` in `.env`. Check API quota in Google AI Studio |
| Firebase auth errors | Run `flutterfire configure` to regenerate `firebase_options.dart`. Check Firebase Console → Authentication → Sign-in method → Email/Password is enabled |
| Code generation errors | Run `flutter pub run build_runner build --delete-conflicting-outputs` |
| `dart:io` errors on web | Ensure all file operations use `Uint8List` bytes, not `File` objects. Guard platform-specific code with `kIsWeb` |
